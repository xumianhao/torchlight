# 归档区

`archive/` 用于保存不再适用于当前维护目标、但仍具有历史脉络或诊断价值的内容。归档是保留与标记，不是删除。

## 归档记录

归档时必须保留原始元数据、来源记录、原路径、归档日期、归档原因，以及可用时的替代内容链接。必须保留状态迁移历史或迁移记录，不得删除。内容状态与迁移过程遵循 `governance/freshness-policy.md`：归档前后均不得抹除受影响结论、冲突证据或来源溯源信息。

## 当前使用限制

已归档材料不能直接用于回答当前赛季问题；只有完成新的国服核验后，才可作为当前结论的依据。归档资料本身可以提供历史背景，但不得因此绕过现行赛季的来源、时效或可信度要求。正式结论及其证据不得使用国际服资料。

## 恢复规则

恢复内容必须完成国服核验，并按正常的内容状态迁移更新核验日期、触发原因、受影响结论与关联链接。不得静默地把文件移回活跃目录，也不得仅因历史名称或机制相似就恢复为 `current`。
