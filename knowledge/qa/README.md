# 问答知识区

`knowledge/qa/` 收录可重复使用的玩家问答。每条问答应回答反复出现的问题，并链接其依据的稳定知识或赛季知识，方便追溯具体结论。

## 证据与元数据

问答不是脱离证据的快捷结论。每个正式条目均须包含自身的国服服务器、适用赛季、创建与核验日期、内容状态和可信度元数据；即使证据来自关联知识，也必须在问答中可追溯地说明。

涉及数值、市场、机制或其他时效性内容的问题，应路由至对应赛季的证据，并设置重新核验条件。缺少足够依据的一次性问题应登记至 `governance/pending-verification.md`，不得写成正式问答。

## 模板

每一篇正式问答必须使用 `templates/qa-entry.md`，并完整填写其中要求的条件化回答、例外、来源、关联文档与重新核验条件。
