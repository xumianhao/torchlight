# 稳定知识区

`knowledge/core/` 用于存放不刻意绑定单一赛季的国服概念、规则与可复用知识。稳定不等于永久正确；即使资料适用范围为 `stable`，仍会受国服补丁、赛季或机制调整影响，必须按时效政策重新核验。

## 写入条件

每篇正式文档仍必须完整记录 `server: 国服`、创建与核验日期、内容状态、可信度及重新核验触发条件。正式结论及其证据不得使用国际服资料。资料的事实依据、来源记录与状态迁移必须遵循 `AGENTS.md` 和 `governance/` 中的规范。

## 排除边界

赛季专属数值、市场、BD、活动及平衡结论不属于本目录，应写入对应的 `knowledge/seasons/<season-id>/`。不得因某项结论目前未变化，就将本应随赛季或补丁核验的内容当作稳定知识。

如一篇稳定文档新增赛季依赖章节，应将这些章节移至对应赛季目录，并在两处文档之间建立双向链接；稳定文档只保留不依赖该赛季的内容与必要的导航说明。

## 目录组织

仅当首篇真实文档需要明确主题归属时，才创建聚焦主题的子目录。不得为预期主题预先创建空目录树。
