# 赛季知识区

`knowledge/seasons/` 用于存放具有赛季时效性的国服 BD 与策略资料。新赛季目录路径固定为 `knowledge/seasons/<season-id>/`。

## 赛季标识与元数据

`<season-id>` 必须是稳定、文件系统安全的标识符；其选取和含义应记录在该赛季的 README 中。国服官方中文赛季名称保留在各文档及赛季 README 的元数据中，不以中文名称替代路径标识。正式结论及其证据不得使用国际服资料。

每个已填充内容的赛季目录必须有自己的 README，记录官方名称、标识符、赛季开始背景、已知补丁范围，以及最后一次仓库复核日期。已填充内容的赛季必须包含以下一级目录：

- `builds/`
- `strategies/`

本脚手架不创建任何具体当前赛季目录。

## 换季与复用

新赛季开始时，受影响的既有内容必须由 `current` 标为 `needs-review`。未完成国服核验前，不得把旧内容复制或标记为新赛季的 `current`。

跨赛季复用必须引用较早的具体文件，并记录本次重新核验了哪些结论、所依据的国服版本或资料，以及相应的状态迁移。旧赛季结论不会因名称或历史效果相似而自动适用于当前赛季。
